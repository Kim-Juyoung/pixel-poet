# 🌸 픽셀 시인 (pixel-poet)

단어 세 개를 입력하면 한국어 시를 생성해주는 CLI 도구입니다.

## 실행 방법

```bash
python3 poet.py
```

## 사용 방법

프롬프트가 나타나면 단어 세 개를 쉼표로 구분해서 입력하세요.

```
단어 세 개를 입력하세요 (쉼표로 구분, 예: 바람,별,강): 바람,별,강
```

- 쉼표(`,`), 전각 쉼표(`，`), 공백 모두 구분자로 사용 가능합니다.
- 시가 출력된 후 `y`를 입력하면 다시 쓸 수 있고, `n`을 입력하면 종료됩니다.
- `Ctrl+C`로도 종료할 수 있습니다.

## 요구 사항

- Python 3.6 이상
